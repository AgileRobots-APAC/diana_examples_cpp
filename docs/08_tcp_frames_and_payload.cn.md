# 08 TCP、坐标系与负载

`07_tcp_and_frames` 只读取当前 TCP、默认活动 TCP、默认 TCP/工件坐标系名称和活动 TCP 负载。先确认这些配置，再讨论工具坐标系下的运动；不要在入门例程中直接修改 TCP、负载或工件坐标系。

查询默认 TCP 或工件坐标系名称时，SDK 要求调用方传入至少 256 字节的名称缓冲区；示例已遵守该约束。

负载包含质量、质心和惯量，会影响轨迹规划、动力学补偿与力控接口。

工具相对偏移通过“当前 TCP 齐次矩阵 × 工具坐标系下的相对变换”换算为基坐标系目标。`--offset=x,y,z,roll,pitch,yaw` 的位置单位为 m、角度单位为度；示例只计算并打印目标，不执行运动。
