# 03 机器人状态、错误与诊断

## 回调错误

`initSrv` 注册 error callback。例程中的回调调用：

```cpp
formatError(error_code, ip)
```

打印错误码及字符串描述。

## API 返回值

大量常用 API 使用：

```text
0  成功
-1 或 <0 失败
```

调用失败后不要继续假设运动已经执行。

## 常见运动类错误

控制接口资料列出了例如：

- IK_SINGULAR：逆解奇异
- IK_POSITION_LIMIT：逆解关节位置超限
- IK_FAILURE：逆解失败
- PLAN_JOINTS：关节规划失败
- SPEED_LIMIT_CART：笛卡尔速度超限
- TORQUE_LIMIT：力矩超限

实际处理时应结合 `formatError`、机器人状态和示教器报警信息判断。

## 回调注意事项

错误回调可能运行在后台线程中：

- 不要长时间 `sleep`
- 不要做复杂阻塞 I/O
- 只做记录、状态置位或快速通知

## 诊断数据

`02_robot_state` 除关节、TCP、速度、电流和力矩外，还读取链路状态、最近错误/警告、碰撞标志、TCP 六维外力和各关节外力/力矩。该例程只读，不会发送运动或配置写入命令。

最近错误和警告是 SDK 保存的最近代码，应结合示教器报警与发生时间判断。奇异位姿附近的 TCP 外力可能无效；不要为了获得读数而移动机器人。
