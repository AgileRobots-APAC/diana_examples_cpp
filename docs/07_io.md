# 07 I/O

Diana API provides digital and analog I/O access APIs.

## Digital Inputs

```cpp
readDI("board", "di0", value, ip);
```

## Digital Outputs

```cpp
readDO("board", "do0", value, ip);
writeDO("board", "do0", value, ip);
```

Common `group_name` examples include:

```text
board
plc
endpoint
```

Use the controller I/O configuration as the source of truth for signal names and wiring.

## Analog I/O

Read APIs return both mode and value:

```cpp
readAI("board", "ai0", mode, value, ip);
readAO("board", "ao0", mode, value, ip);
```

Analog output through `writeAO` involves output mode and valid range. Before using it on real equipment, confirm field wiring, mode, and load.

## Safety Policy in This Repository

`06_io` is read-only by default and does not change DO.

It calls `writeDO` only when this option is explicitly passed:

```bash
./bin/06_io 192.168.10.75 --set-do=1
```

`06_io` also reads controller bus current and voltage, and supports explicit AO writes with `--set-ao=<mode>:<value>`. AO writes affect external equipment, so confirm the controller signal mode, wiring, and allowed range first.
