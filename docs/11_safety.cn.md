# 11 安全说明

> 任何运动示例都只能作为 API 调用参考。客户必须根据实际机器人型号、安装方式、工具、负载和现场风险评估后运行。

## 首次运行前

- 确认急停按钮随时可触及。
- 机器人运动范围内无人、无障碍物。
- 确认工具安装牢固、TCP 和负载配置正确。
- 从低速度、低加速度开始。
- 不要直接复制其他机器人现场的绝对关节角或绝对位姿。

## 为什么本仓库运动例程默认不动

`03_joint_motion` 和 `04_cartesian_motion` 默认：

1. 连接机器人。
2. 读取当前位置。
3. 计算一个很小的示例目标。
4. 打印目标。
5. **不发送运动指令。**

只有显式加入 `--run` 才执行。

## `releaseBrake`

API 手册说明调用 `releaseBrake` 后应等待约 2 秒再做其他操作。例程遵循这一点。

## `stop`

`stop` 用于停止当前任务。不要把示例程序的软件停止逻辑当成急停功能的替代品。

## 现场发布

公开给客户前，建议由机器人应用/安全负责人对每个会运动的例程做一次真机验证并固定推荐速度范围。
